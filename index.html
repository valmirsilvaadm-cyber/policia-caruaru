♻️ Restaurar Dados

Por segurança, esta tela só restaura dados técnicos/administrativos (usuários, permissões, config do sistema, chamados, erros, dispositivos) — os mesmos que a Tecnologia já pode gerenciar. Dados operacionais (escalas, plantões, ocorrências, armamento) não são restaurados por aqui de propósito: isso evita que a Tecnologia sobrescreva decisões de outros setores. Para restaurar dados operacionais, é preciso acesso de administrador via Cloud Shell.
